# Бот для рассылки с inline-кнопками

Бот отправляет людям в личные сообщения пост с **inline-кнопками** (под сообщением):
- **кнопки-ссылки** — открывают сайт, канал, любую ссылку;
- **кнопки-popup** — по нажатию показывают всплывающее окно с текстом.

Пост копируется целиком: жирный шрифт, ссылки, фото, видео — всё сохраняется. Перед отправкой
ты видишь предпросмотр.

## Важно: Telegram не даёт боту писать первым

Бот может написать человеку только тогда, когда тот уже писал боту. Поэтому получатели
должны сами нажать **/start** у бота. Дай им ссылку `https://t.me/<username_бота>` и попроси
нажать «Запустить». После этого бот запомнит их и сможет присылать рассылки.

Рассылай только тем, кто на это согласился. Иначе бота могут заблокировать.

## Как это работает

1. Ты пишешь боту пост (текст, фото, видео — что угодно).
2. Присылаешь кнопки или `/skip`, если кнопки не нужны.
3. Бот показывает предпросмотр и спрашивает: **всем подписчикам** или **одному человеку**.
4. После отправки бот присылает отчёт: сколько доставлено и сколько людей недоступны.

Подписчики — все, кто написал боту, кроме тех, кто отправил `/stop`. Если человек заблокировал бота,
он выпадает из рассылки после первой неудачной отправки.

## Быстрый старт (на своём компьютере)

Нужен Python 3.10 или новее.

```bash
cd inline-buttons-bot
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
```

1. Создай бота в Telegram у [@BotFather](https://t.me/BotFather): команда `/newbot`. Скопируй токен.
2. Открой `.env` и впиши токен в `TELEGRAM_BOT_TOKEN`.
3. Запусти бота: `python main.py`.
4. Открой своего бота в Telegram, нажми `/start` и отправь `/id`. Бот ответит твоим ID.
5. Впиши этот ID в `ADMIN_IDS` в `.env` и перезапусти `python main.py`.

Теперь ты админ, и можно делать рассылки.

## Как сделать рассылку

Пример: нужен пост с двумя кнопками.

1. Отправь боту текст поста (можно с **жирным** и ссылками, можно фото с подписью).
2. Бот ответит «Пост сохранён». Отправь кнопки в формате, описанном ниже:
   ```
   Сайт - https://example.com | Поддержка - https://t.me/support
   ```
   Или отправь `/skip`, если кнопки не нужны.
3. Бот покажет предпросмотр, то есть то, что увидят получатели, и три кнопки:
   - **📢 Всем подписчикам (N)** — отправить всем;
   - **👤 Одному человеку** — попросит `@username` или числовой ID;
   - **✖ Отмена**.
4. После отправки бот пришлёт отчёт.

### Формат кнопок

Каждая строка — отдельный ряд. Кнопки в одном ряду разделяются символом `|`.

```
Текст кнопки - https://ссылка
Кнопка 1 - https://ссылка1 | Кнопка 2 - https://ссылка2
Подробнее - popup: текст во всплывающем окне (до 200 символов)
```

- Название и значение разделяются ` - ` (дефис с пробелами вокруг).
- Ссылка должна начинаться с `https://`, `http://` или `tg://`.
- Символ `|` нельзя использовать внутри текста кнопки.

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/start` | все | подписаться на рассылку |
| `/stop` | все | отписаться |
| `/id` | все | показать свой Telegram ID |
| `/help` | все | справка |
| `/cancel` | админ | отменить текущий пост |
| `/skip` | админ | пост без кнопок |
| `/stats` | админ | статистика подписчиков |

## Настройки

| Переменная | Обязательна | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен от @BotFather |
| `ADMIN_IDS` | да, для рассылок | Telegram ID админов через запятую |
| `DB_PATH` | нет | файл базы подписчиков, по умолчанию `data/bot.db` |

Если `ADMIN_IDS` не задан, бот всё равно запустится. Админ-функции будут отключены, а `/start` и `/id` работают.

## Деплой на justrunmy.app

Бот работает через polling, поэтому отдельный домен и HTTPS не нужны.

1. Собери архив. В готовом виде он уже лежит рядом с папкой проекта как `inline-buttons-bot.zip`.
   Чтобы собрать заново из папки проекта:
   ```bash
   cd inline-buttons-bot
   zip -r ../inline-buttons-bot.zip . -x "data/*" "*__pycache__*" "*.pyc" ".env" ".venv/*"
   ```
   Важно: файлы должны лежать в корне архива (`main.py`, `requirements.txt` и так далее), без вложенной папки.
2. В панели justrunmy.app: **Create Application** → **Python** → загрузи zip → дождись анализа → **Go**.
   Если панель спрашивает версию Python, выбери 3.10 или новее (этого требует aiohttp).
3. В настройках приложения добавь переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `ADMIN_IDS` — твой ID (его можно получить командой `/id` до деплоя или после него).
4. Запусти приложение и открой логи. Должна появиться строка «Бот запущен».
5. Проверь: напиши боту `/id`. Если бот ответил, всё работает.

**Данные.** Подписчики хранятся в файле `data/bot.db`. По описанию justrunmy.app данные на диске
сохраняются между перезапусками. Перед тем как загрузить новую версию архива, всё же сохрани
файл `data/bot.db` через файловый менеджер или веб-шелл панели. Так подписчики точно не потеряются.

**Один токен — один экземпляр.** Если бот запущен и на компьютере, и на хостинге, Telegram вернёт
ошибку `Conflict`. Останови одну из копий.

**Если приложение не запускается или перезапускается по кругу:**
- `Не задан TELEGRAM_BOT_TOKEN` — добавь переменную в настройках приложения.
- `Telegram не принял токен (ошибка 401)` — токен введён с ошибкой или перевыпущен. Возьми актуальный токен у @BotFather (`/revoke`) и вставь его заново.
- `нет связи с Telegram` — бот сам повторяет попытки. Если сообщение не пропадает, проверь, что хостинг может обращаться к `api.telegram.org`.
- `OOMKilled` или нехватка памяти — загрузи актуальную версию архива. Старые версии на aiogram занимали около 165 МБ только на импорт. Текущая версия работает на aiohttp и занимает около 40 МБ.

## Ограничения

- Один пост — одно сообщение. Альбомы (несколько фото или видео одним сообщением) не поддерживаются: сохранится только первое сообщение альбома, остальные бот пропустит с подсказкой.
- Текст popup-окна — до 200 символов (ограничение Telegram).
- Popup-кнопка только показывает текст. Если нужна другая логика по нажатию, её надо дописать в `popup_pressed` в `main.py`.
- Рассылка идёт примерно по 20 сообщений в секунду, поэтому на большую аудиторию она занимает несколько минут.
- Людей, которые заблокировали бота или ни разу не нажимали `/start`, бот помечает как недоступных и больше им не пишет.

## Структура

```
inline-buttons-bot/
├── main.py           точка входа: команды, сценарий поста, рассылка
├── telegram_api.py   клиент Telegram Bot API на aiohttp
├── buttons.py        разбор текста с кнопками и сборка клавиатуры
├── db.py             SQLite: подписчики и тексты popup-окон
├── requirements.txt  зависимости
├── .env.example      шаблон настроек
└── tests/            тесты
```

Бот не использует aiogram: при импорте он занимал около 165 МБ памяти, поэтому на хостинге с
небольшим лимитом процесс падал с OOMKilled. Для нескольких методов Bot API достаточно простых
HTTP-запросов через aiohttp.

## Тесты

```bash
python -m unittest
```

Тесты не ходят в сеть. Сценарии бота прогоняются через подменённый клиент Telegram. Клиент
`telegram_api.py` проверяется на локальном HTTP-сервере.
