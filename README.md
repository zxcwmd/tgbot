# Telegram-магазин файлов

Бот продаёт цифровые файлы за Telegram Stars (XTR). Каталог и заказы хранятся в SQLite; сами документы остаются в Telegram, бот отправляет их по `file_id`.

## Настройка и запуск

1. Создайте бота через `@BotFather` и получите токен. Если этот бот раньше работал через webhook, сначала отключите webhook.
2. Задайте переменные окружения: `BOT_TOKEN` — токен, `ADMIN_ID` — числовой Telegram ID продавца, `SUPPORT_CONTACT` — контакт поддержки (например, ваш `@username`). Не добавляйте токен в репозиторий.
3. Для локального запуска используйте `python bot.py` (Python 3.10+, сторонние библиотеки не нужны). По умолчанию база находится в `data/shop.sqlite3`; путь можно изменить через `DB_PATH`.

### JustRunMy.App

Разверните репозиторий через Git Push или загрузите ZIP с `Dockerfile` и `bot.py`. Укажите переменные в панели приложения. Если при загрузке ZIP сервис не применил Dockerfile автоматически, используйте Docker Image или Git Push с Dockerfile. Бот работает через long polling: публичный порт, HTTPS и webhook не нужны. Запускайте **один** экземпляр.

Подключите постоянное хранилище к `/data` либо задайте `DB_PATH` внутри другого каталога, который сохраняется при пересоздании контейнера. Проверьте сохранность базы после тестового передеплоя и настройте резервное копирование до начала продаж. Если тариф не позволяет сохранить данные между деплоями, не запускайте реальные продажи на нём. [На сайте JustRunMy.App](https://justrunmy.app/) указана поминутная оплата ресурсов; постоянный бесплатный тариф не подтверждён.

## Продажи

- В личном чате с ботом отправьте файл **как документ** с подписью `50 Мой файл`: 50 — цена в звёздах, дальше название товара. Повторите для каждого файла.
- Покупатель открывает `/catalog`, выбирает команду `/buy_ID` и оплачивает счёт. Файл отправляется в тот же чат только после подтверждённой оплаты. Команды для повторной выдачи нет; если отправка не удалась, бот автоматически повторит попытку. В редком случае сбоя между отправкой и записью результата возможна повторная отправка.
- `/hide ID` скрывает товар и запрещает создание новых счетов. Уже созданные счета остаются действительными по старой цене и на старый файл.
- `/terms` показывает условия, `/paysupport` — контакт для вопросов по оплате и возврату. Автоматических возвратов нет.

Перед публикацией проверьте покупку с отдельного аккаунта на тестовом товаре и убедитесь, что файл приходит только после оплаты.
